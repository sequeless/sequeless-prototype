# Issue Tracker: GitHub

Issues for this repo live in **GitHub Issues**.

## Creating issues

Use `gh issue create` to open a new issue from the CLI:

```bash
gh issue create --title "..." --body "..."
```

Or open a new issue in [the GitHub UI](https://github.com/sequeless/sequeless-prototype/issues/new).

## Reading issues

Fetch issues via the `gh` CLI or the GitHub UI.

## PRs as a request surface

**Off** (default). PRs are not triaged; issues are. If you want to enable PRs for triage, edit this file and set `allow_prs: true`.
